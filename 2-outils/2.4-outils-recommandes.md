# Outils recommandés pour démarrer

Voici les outils les plus utiles pour un projet web débutant.

## Éditeur

- **Visual Studio Code** : simple, extensible et populaire.
- Installe les extensions pour ton langage, le formatage et Git.

## Versionnage

- **Git** : indispensable.
- **GitHub / GitLab** : pour héberger ton code et garder une copie distante.

## Terminal

- Un terminal fonctionnel permet de lancer les commandes et de lire les logs.
- Sur Linux, le terminal intégré à VS Code ou `gnome-terminal` suffit.

## Test d’API

- **Thunder Client** ou **Postman** : tester rapidement les endpoints.

## Qualité du code

- **ESLint** : détecte les erreurs et les mauvaises pratiques.
- **Prettier** : formate le code automatiquement.

## Base de données

- **SQLite** : simple pour un projet local.
- **PostgreSQL** : bon passage quand tu progresses.

## Hébergement

- **Vercel / Netlify** : pour un frontend.
- **Railway / Render** : pour backend ou fullstack.

## Conseil

Commence avec un petit ensemble d’outils. Apprends à bien les utiliser avant d’en ajouter d’autres.
