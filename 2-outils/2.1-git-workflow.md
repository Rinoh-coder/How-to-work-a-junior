# Workflow Git pour débutant

Un workflow Git simple t’aide à travailler proprement, même en solo.

## Principes de base

- `main` est la branche stable.
- `develop` est la branche d’intégration.
- chaque fonctionnalité a sa propre branche.
- on pousse souvent.

## Branches temporaires

- `feature/nom` : nouvelle fonctionnalité.
- `fix/nom` : correction de bug.
- `chore/nom` : tâche technique.
- `docs/nom` : documentation.

## Cycle standard

1. Mettre à jour la base :

```bash
git checkout develop
git pull origin develop
```

2. Créer une branche :

```bash
git checkout -b feature/ma-fonctionnalite
```

3. Travailler et commiter régulièrement.
4. Pousser la branche :

```bash
git push -u origin feature/ma-fonctionnalite
```

5. Fusionner après test :

```bash
git checkout develop
git pull origin develop
git merge --no-ff feature/ma-fonctionnalite
```

6. Nettoyer :

```bash
git push origin develop
git branch -d feature/ma-fonctionnalite
git push origin --delete feature/ma-fonctionnalite
```

## Pourquoi ce workflow

- ton historique reste lisible,
- chaque travail est isolé,
- tu peux revenir facilement en arrière,
- tu gardes une branche stable sur `main`.

## Commandes utiles

- `git status`
- `git log --oneline --graph`
- `git branch`
- `git add -p`
- `git commit -m "message"`
- `git push origin <branche>`
