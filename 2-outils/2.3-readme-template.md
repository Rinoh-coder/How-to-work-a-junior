# Modèle de README

Un bon README permet à quelqu’un de comprendre ton projet et de le lancer rapidement.

## Structure recommandée

1. Titre
2. Description courte
3. Prérequis
4. Installation
5. Commandes
6. Structure du projet
7. Contribution
8. Licence

## Exemple


# Nom du projet

Un outil simple pour [décrire le problème résolu].

## Prérequis

- Node.js 20+
- Git

## Installation

```bash
npm install
```

## Lancer le projet

```bash
npm run dev
```

## Commandes utiles

- `npm run dev` : démarrer en développement
- `npm run build` : créer la version de production
- `npm run test` : lancer les tests

## Structure du projet

- `src/` : code source
- `tests/` : tests automatisés
- `docs/` : documentation
- `README.md` : guide d'installation

## Contribution

1. Créer une branche `feature/...`
2. Faire des commits clairs
3. Ouvrir une pull request


## Pourquoi c’est important

Le README est souvent le premier document que l’on lit. Il doit donner confiance et permettre d’avancer sans chercher.
