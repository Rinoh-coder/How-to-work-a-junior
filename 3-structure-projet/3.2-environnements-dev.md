# Environnement de développement

Un bon environnement permet de travailler de manière stable et reproductible.

## Pourquoi c’est important

- le code marche de la même manière partout,
- les erreurs apparaissent plus tôt,
- le projet reste facile à partager.

## Les éléments essentiels

### 1. Versionner les outils

Utilise des versions fixes pour Node, Python ou Docker.

- `.nvmrc` pour Node,
- `runtime.txt` pour Python.

### 2. Gérer les secrets

Ne mets pas de secrets dans le dépôt.
Crée `.env.example` et laisse chaque développeur créer son `.env`.

### 3. Configurer `.gitignore`

Ignore les dossiers générés et les fichiers privés :

- `node_modules/`
- `dist/` ou `build/`
- `.env`
- fichiers système.

### 4. Installer les dépendances

JavaScript :

```bash
npm install
```

Python :

```bash
pip install -r requirements.txt
```

### 5. Scripts de démarrage

Ajoute ces commandes utiles :

- `npm run dev`
- `npm run start`
- `npm run test`

### 6. Vérifier l’installation

Teste avec :

```bash
npm run dev
```

Si le projet démarre, c’est bon.

## Bonnes pratiques

- documente l’installation dans le README,
- partage les réglages d’éditeur utiles,
- ne change pas de version sans raison.

## Mise en route rapide

1. installer Git,
2. installer Node.js,
3. cloner le dépôt,
4. copier `.env.example` en `.env`,
5. lancer `npm install`,
6. lancer `npm run dev`.
