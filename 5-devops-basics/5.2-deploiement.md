# Déploiement

Le déploiement rend ton application accessible en ligne.

## Avant de déployer

Assure-toi que :

- le projet fonctionne localement,
- les tests passent,
- la documentation est à jour,
- les secrets ne sont pas dans le dépôt.

## Choisir une cible

- **Front-end statique** : Vercel, Netlify, GitHub Pages.
- **Backend ou fullstack** : Railway, Render, Heroku, Fly.io.
- **API seule** : une plateforme qui gère les variables d’environnement.

## Étapes

### 1. Préparer la build

- ajouter une commande `build` si nécessaire,
- vérifier les chemins relatifs.

### 2. Gérer les variables d’environnement

- ne stocke pas les secrets dans le code,
- utilise `.env.example`,
- configure les variables sur la plateforme.

### 3. Tester en ligne

- vérifie l’URL,
- teste les pages ou endpoints principaux,
- compare avec le comportement local.

### 4. Mettre à jour le README

Ajoute l’URL et les commandes de déploiement.

## Checklist

- [ ] le build passe localement,
- [ ] les tests critiques sont verts,
- [ ] le dépôt est propre,
- [ ] les secrets ne sont pas dans le code,
- [ ] l’application se lance sur la plateforme,
- [ ] l’URL fonctionne.

## Conseils

- déploie d’abord sur un environnement de test,
- ne modifie pas la production directement,
- garde une copie locale du processus.
