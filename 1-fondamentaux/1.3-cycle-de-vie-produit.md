# Cycle de vie d’un produit logiciel

Ce guide décrit les étapes d’un projet logiciel : de l’idée au déploiement en passant par la maintenance.

## 1. Idée et cadrage

Objectif : transformer une idée vague en un problème concret.

- définir le besoin,
- identifier l’utilisateur cible,
- décider du périmètre minimal.

Livrable : une phrase problème + un MVP simple.

## 2. Spécification

Objectif : dire précisément ce que le produit fera.

- lister les fonctionnalités essentielles,
- écrire des user stories,
- choisir la stack technique.

Livrable : `specs.md` avec le périmètre et les critères de réussite.

## 3. Développement

Objectif : construire le MVP proprement.

- initialiser le projet,
- structurer les dossiers,
- configurer les outils de qualité,
- coder par petites étapes.

Livrable : un prototype fonctionnel et testable.

## 4. Livraison

Objectif : mettre à disposition une version utilisable.

- vérifier que le projet démarre,
- déployer si possible,
- documenter les commandes et l’usage.

Livrable : un README à jour et, si possible, une version en ligne.

## 5. Maintenance

Objectif : améliorer le produit sans le casser.

- corriger les bugs,
- ajouter les améliorations utiles,
- conserver une base propre.

Livrable : un backlog clair et un historique de versions.

## À retenir

Un projet évolue par petites étapes. À chaque phase, vérifie que tu avances vers l’objectif principal.
