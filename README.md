# How-to-work-a-junior

#  Comment je bosse : Guide de bonnes pratiques pour développeur solo

> *"Code comme si le prochain développeur qui maintiendra ton code était un psychopathe qui connaît ton adresse."* - Anonyme

##  Objectif

Ce repository est mon manifeste de développement. Il documente mes méthodes,
mes outils et mes standards pour :
-  Produire un code de qualité professionnelle
-  Pouvoir reprendre n'importe quel projet après 6 mois d'absence
-  Préparer ma transition vers le travail en équipe
-  Aider les autres développeurs juniors à structurer leur pratique

-  Développeurs juniors qui veulent professionnaliser leur pratique
